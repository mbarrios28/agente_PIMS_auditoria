# Base normativa de la entrega: ISO/IEC 27701:2025

La base normativa exclusiva del agente es ISO/IEC 27701:2025, segunda edición.
La copia original y su OCR completo están versionados en ISOS. El contexto y los criterios
organizativos de cálculo se obtienen de GESTITEL; no son requisitos adicionales de otra norma.

| Referencia de ISO 27701:2025 | Cómo interviene en el agente | Límite |
|---|---|---|
| 6.1.2, PDF 13–14 | Escenarios y valoración; consecuencias para la organización y las personas | Estimaciones bajo criterios recuperados, no evaluación exhaustiva |
| 6.1.3, PDF 14–15 | Estrategia, medidas, responsable propuesto, plazo y evidencia a solicitar | No aprueba SoA ni acepta riesgo residual |
| 8.2 / 8.3, PDF 18 | Evaluación bajo solicitud y registro del tratamiento propuesto | No ejecuta el tratamiento ni verifica por sí solo su eficacia |
| Anexo A, PDF 21–26 | Controles de referencia según rol y escenario | La aplicabilidad necesita evidencia del tratamiento de PII |
| Anexo B, PDF 27–56 | Orientación para fundamentar acciones propuestas | Debe recuperarse y citarse; no completar requisitos de memoria |
| A.3.24 / B.3.24 | Referencias propias de esta edición para copias de información | Una copia declarada no equivale a una restauración probada |

La búsqueda del agente solo recupera el PDF OCR de ISO 27701:2025. Conserva ID y página.
Las correspondencias informativas de los anexos C–F no amplían la base normativa.
Los códigos de otras normas que aparezcan en el catálogo GESTITEL son datos operativos:
no se presentan como controles de ISO 27701.

Ver `../integridad_iso_27701.md`. Para repetir la comprobación:
`python scripts/verificar_iso_27701.py` desde la raíz.
El OCR puede tener errores; las citas y tablas requieren contraste visual con el original.
La herramienta no certifica cumplimiento.

La evidencia histórica `evidencia_ejecucion.json` y su informe se conservan sin alterar.
Son anteriores al aislamiento normativo actual y no demuestran la recuperación ISO actual.
