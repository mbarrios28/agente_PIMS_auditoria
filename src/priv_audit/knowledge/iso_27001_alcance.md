# ISO/IEC 27001:2022 — ficha de alcance
Síntesis editorial del alcance público, no texto normativo completo.
ISO/IEC 27001 establece requisitos para un sistema de gestión de seguridad de la información,
incluidos requisitos de evaluación y tratamiento de riesgos adaptados a la organización.
Fuente: https://www.iso.org/standard/27001
Esta ficha no permite validar conformidad por cláusula ni acreditar implementación de controles.
El agente genera propuestas para revisión humana; sus resultados no equivalen a certificación.
